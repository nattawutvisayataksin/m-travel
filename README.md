# 🧳 M-Travel — เว็บบันทึกท่องเที่ยวส่วนตัว

เว็บบันทึกการเดินทางส่วนตัวแบบง่าย ๆ สไตล์เดียวกับ [nattawutweb.com](https://nattawutweb.com) (ธีม Hitchcock)
เอาไว้ **แสดงโชว์ทริป** และ **บันทึกไว้หัวขึ้นหัวตำ กันลืม** — เขียนจาก HTML/CSS/JS ล้วน ไม่ต้อง build
จึง deploy ขึ้น Serverless ได้ทุกแพลตฟอร์มในไม่กี่นาที

## 🚀 เริ่มใช้งานใน 4 ขั้นตอน

### 1) ลองเปิดดูก่อน (ไม่ต้องตั้งค่าอะไร)

ดับเบิลคลิกเปิด `index.html` ในเครื่อง หรือรันเซิร์ฟเวอร์จิ๋ว:

```bash
# ถ้ามี Python
python -m http.server 8080
# หรือถ้ามี Node
npx serve .
```

แล้วเปิด `http://localhost:8080` — เว็บจะอยู่ใน **โหมดตัวอย่าง** แสดงทริปสาธิต 6 ทริปให้ดูหน้าตา

### 2) สร้างฐานข้อมูล Supabase (ฟรี)

1. สมัคร/ล็อกอินที่ [supabase.com](https://supabase.com) แล้วกด **New project**
2. เปิดเมนู **SQL Editor** → **New query**
3. เปิดไฟล์ `supabase-schema.sql` ในโปรเจกต์นี้ **แก้อีเมล** `you@example.com` ให้เป็นอีเมลของคุณก่อน (บรรทัด `insert into public.admins`)
4. วางทั้งไฟล์ลง SQL Editor แล้วกด **Run**
5. เปิดเมนู **Authentication → Sign In / Up → Email** ให้สถานะเปิดใช้งาน

### 3) เอาคีย์มาใส่ในเว็บ

ไปที่ **Settings → API** ใน Supabase แล้วคัดลอก 2 ค่านี้ไปใส่ใน `assets/js/config.js`:

```js
window.SUPABASE_CONFIG = {
  url: "https://xxxxxxxx.supabase.co",   // Project URL
  anonKey: "eyJhbGciOi...",              // anon public key
};
```

> 🔒 `anonKey` เป็นคีย์สาธารณะ ใส่ในโค้ดฝั่งหน้าเว็บได้ปลอดภัย — สิทธิ์จริงถูกคุมด้วย
> Row Level Security ใน SQL (คนทั่วไปอ่านได้เฉพาะทริปที่เผยแพร่, เขียนได้เฉพาะอีเมลในตาราง `admins`)

### 4) Deploy แล้วเริ่มบันทึก

Deploy ตามวิธีด้านล่าง แล้วเข้าหน้า `your-site.com/admin.html`
กด **"สมัครครั้งแรก"** ด้วยอีเมลเดียวกับที่ใส่ไว้ในตาราง `admins` → เริ่มเพิ่มทริปได้เลย

## ☁️ วิธี Deploy (เลือกอย่างใดอย่างหนึ่ง)

### Netlify (ง่ายสุด — ลากวางได้)

- **วิธีลากวาง:** เข้า [app.netlify.com/drop](https://app.netlify.com/drop) แล้วลากโฟลเดอร์ `M-Travel` ทั้งโฟลเดอร์ใส่ — เสร็จจบ ได้เว็บทันที
- **วิธีเชื่อม Git:** Push โปรเจกต์ขึ้น GitHub → Netlify → **Add new site → Import an existing project** → เลือก repo → Build command ว่างไว้, Publish directory = `.` → Deploy

### Vercel

1. Push โปรเจกต์ขึ้น GitHub
2. เข้า [vercel.com](https://vercel.com) → **Add New → Project** → เลือก repo
3. Framework Preset เลือก **Other** (ไม่ต้องใส่ build command อะไรทั้งสิ้น) → **Deploy**

### Cloudflare Pages

1. เข้า [pages.cloudflare.com](https://pages.cloudflare.com) → **Create a project → Connect to Git**
2. เลือก repo → Build command ว่าง, Build output directory = `/` → **Save and Deploy**

### GitHub Pages

1. Push โปรเจกต์ขึ้น repo
2. **Settings → Pages → Source: Deploy from a branch** → เลือก branch `main` / folder `/ (root)` → Save
3. เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

> 💡 เว็บนี้เป็น static ล้วน + เรียก Supabase ตรงจากเบราว์เซอร์ จึงไม่ต้องมี server function ใด ๆ
> โฮสติงไฟล์นิ่งแบบนี้ใช้ฟรีตลอดได้ในระดับการใช้งานส่วนตัวสบาย ๆ

## 📝 การใช้งานประจำวัน

### เพิ่มทริปใหม่
1. เข้าหน้า **ผู้ดูแล** → ล็อกอิน → กด **เพิ่มทริป**
2. กรอกชื่อทริป ประเทศ เมือง ช่วงวันเดินทาง
3. อัปโหลด**ภาพปก** (รูปเด่นที่สุดของทริป) และ**รูปแกลเลอรี**หลายรูปพร้อมกันได้
4. เขียนบทสรุปสั้น + เนื้อหายาว — ช่องเนื้อหาเป็น**ตัวแก้ไขแบบรวย**: ปุ่ม **B / I / U** (หรือ Ctrl+B, Ctrl+I, Ctrl+U) ทำตัวหนา–เอียง–ขีดเส้นใต้, ปุ่ม **ลิงก์** แทรกลิงก์เว็บ, ปุ่ม **• ลิสต์** ทำหัวข้อย่อย, กด Enter ขึ้นย่อหน้าใหม่ + จุดเด่นทริป (บรรทัดละ 1 ข้อ)
5. กด **บันทึกทริป** — ทริปจะโผล่บนหน้าแรกทันที

### ตั้ง "ฉบับร่าง"
ในตารางรายการทริป สวิตช์ **เผยแพร่** ปิดได้ — ทริปจะยังไม่แสดงให้คนอื่นดู แต่คุณเห็นตอนล็อกอินอยู่

### แก้ชื่อเว็บ / ภาพหน้าปก / หน้าเกี่ยวกับฉัน
หน้าผู้ดูแล → **ตั้งค่าเว็บ** — แก้แล้วกดบันทึก ทุกหน้าอัปเดตทันที

### สำรองข้อมูล
หน้าผู้ดูแล → **ส่งออก** จะได้ไฟล์ `.json` เก็บไว้เป็นหลัก (รูปเก็บอยู่ใน Supabase Storage แยกต่างหาก)
ย้ายโปรเจกต์/เปลี่ยน Supabase ใหม่ → กด **นำเข้า** ใส่ไฟล์เดิมกลับได้

## 🎨 ปรับแต่งหน้าตาเว็บ

แก้สีและฟอนต์ได้ที่ตัวแปรด้านบนของ `assets/css/style.css`:

```css
:root {
  --accent: #3bc492;      /* สีเน้น (เขียวมิ้นต์แบบต้นแบบ) */
  --dark: #1d1d1d;        /* สีเมนู/footer */
  --font-head: 'Kanit', sans-serif;   /* ฟอนต์หัวข้อ */
  --font-body: 'Sarabun', sans-serif; /* ฟอนต์เนื้อความ */
}
```

ฟอนต์โหลดจาก Google Fonts — เปลี่ยนชื่อฟอนต์ใน `<link>` ของทุกหน้า HTML และตัวแปรด้านบนได้เลย

## ❓ คำถามที่พบบ่อย

**รูปอัปโหลดไม่ได้ / บันทึกไม่ได้ ขึ้น error เรื่อง row-level security?**
อีเมลที่ล็อกอินอยู่ไม่ได้อยู่ในตาราง `admins` — เพิ่มด้วย SQL:
`insert into public.admins (email) values ('อีเมลของคุณ');`

**ลืมรหัสผ่านผู้ดูแล?**
หน้าล็อกอินกด **"ลืมรหัสผ่าน?"** แล้วกรอกอีเมล — ลิงก์ตั้งรหัสใหม่จะถูกส่งไปให้

**อยากลบข้อมูลตัวอย่างออก?**
ข้อมูลตัวอย่างมีแค่ตอนยังไม่เชื่อมต่อ Supabase — พอใส่คีย์ใน `config.js` แล้วเว็บจะอ่านจากฐานข้อมูลจริงทันที (ตอนแรกตารางว่าง หน้าแรกจะขึ้นคำแนะนำให้เพิ่มทริปแรก)

**จำกัดพื้นที่รูปเท่าไร?**
Supabase ฟรีให้ Storage 1 GB — สำหรับบันทึกส่วนตัวใช้ได้ยาว ๆ แนะนำย่อรูปเหลือกว้าง ~1600px ก่อนอัปโหลดจะประหยัดมาก

**อยากย้ายไปใช้แบบไม่มีฐานข้อมูล?**
ข้อมูลส่งออกเป็น JSON ได้อยู่แล้ว — นำไปแปลงเป็นไฟล์ `demo-data.js` ก็กลับเป็นเว็บ static ล้วนได้ทันที
